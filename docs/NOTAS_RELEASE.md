## ⬇️ ¿Qué descargo?

| Archivo | Para quién |
|---|---|
| **`Instalar-MCP-AutoCAD.exe`** | ✅ **La mayoría.** Instalador para Windows: lo instala y lo conecta con Claude Desktop. |
| `MCP-AutoCAD.mcpb` | Si prefieres instalarlo como extensión desde Claude Desktop (doble clic). |
| `MCP-AutoCAD-portatil.zip` | Sin instalar: descomprime en una carpeta fija y abre `mcpautocad.exe`. |

Usa **una sola** de las tres formas.

**Necesitas:** Windows 10/11 (64 bits), AutoCAD completo (no LT) y [Claude Desktop](https://claude.ai/download).
Si Windows muestra «Windows protegió su PC», pulsa **Más información → Ejecutar de todas formas** (el programa aún no
está firmado digitalmente).
